# Note on terminology: 'HOG' is used throughout as a generic term for gene family.

#   OrthoFinder v3 (default):          families are flat Orthogroups from Orthogroups.tsv
#   Both are handled identically by this pipeline; HOG in column names refers to either.
#
# Column definitions:
#   Species/Node                  : Leaf species or internal ancestral node (number matches cafe_node_label_guide.pdf)
#   Total_HOGs_significant        : Number of gene families with a significant branch p-value (p <= 0.05)
#   Expansion_HOGs_significant    : Significant gene families (p <= 0.05) with a net positive gene count change (expansion)
#   Contraction_HOGs_significant  : Significant gene families (p <= 0.05) with a net negative gene count change (contraction)
#   Expansion_genes_significant   : Sum of gene count changes across all significant expanding families (total genes gained)
#   Contraction_genes_significant : Sum of gene count changes across all significant contracting families (negative; total genes lost)
#   Expansion_HOGs_total          : Gene families with any positive gene count change, regardless of significance (no p-value filter)
#   Contraction_HOGs_total        : Gene families with any negative gene count change, regardless of significance (no p-value filter)
